Septa Real-Time Map Micro-interaction: Assignment Alpha

How to Access Real-Time Map

Using the link and then click real time map, then put in a septa line, or route: https://www.septa.org Then clicking on the real time map button, click the certain line or mode of transportation you want then see where they are.

1. Describe how user can locate one object on that web

  • User clicks on real time map after opening Septa's website
  • The map is blank at first have to pick a certain route or line.
  • Once the user selects a route the map will update and show markers of where they are moving.
  • User moves cursor over to a vehical marker and clicks on it to show additional information about next stops, where it's going an if theres any delays

2. Triggers

  • User looks at the vehicle marker
  • Moves cursor onto the marker
  • User Clicks on the marker
  • Marker responds with a message popup that shows train number, information about next stop and inbound or outbound, and message about if it's delayed or on time.
  • The interface responds with zooming into that specific vehicle as well.

3. Rules

  • 1. Selecting a vehicle marker will display information.
  • 2. The map identifies the selected vehicle and displays its current location, next stops, and any delays.
  • 3. Only the selected marker will show the information display.

    • The map will update the other vehicles in real time but the information about them are only listed if you click on it. Selecting different ones will also show it.

4. Feedback

The feedback is mostly visual as a message pops up when they click on it. When they click outside of it the message goes away.

5. Loops and Modes

  • Real-time changes: Location changes happen as septa vehicles move, therefore shows a changing state.
  • Multiple Objects: Contains multiple different markers that can be selected.
  • Filtering: Users can filter out a certain route or service that will show only the relevant markers.
  • De-select: By selecting another option when you are still clicking on one it will switch description information.
  • Zooming: The interface responds with zooming into that specific vehicle as well.
